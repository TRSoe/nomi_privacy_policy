📅   နောက်ဆုံးပြင်ဆင်သောရက် — မေ ၃၁, ၂၀၂၆
🔒 အကျဉ်းချုပ် —
Nomi App သည် သင့် Data အားလုံးကို သင့် Phone ထဲမှာသာ သိမ်းဆည်းသည်။ ကျွန်ုပ်တို့၏ Server သို့ မည်သည့် Data မျှ မပို့ပါ။ Internet ချိတ်ဆက်မှု မလိုဘဲ အလုပ်လုပ်သည်။ သင့် ငွေကြေးဆိုင်ရာ အချက်အလက်များသည် သင့်တစ်ယောက်တည်း အတွက်သာ ဖြစ်သည်။
① ကောက်ယူသော အချက်အလက်များ

Nomi App သည် အောက်ပါ အချက်အလက်များကိုသာ သင့် Phone ထဲတွင် သိမ်းဆည်းသည်—

အချက်အလက်ရည်ရွယ်ချက်သိမ်းဆည်းနေရာ
နာမည် Dashboard တွင် ကြိုဆိုစာ ပြသရန် Phone (Local)
ဝင်ငွေ / ထွက်ငွေ မှတ်တမ်း ငွေကြေး အချက်အလက် ပြသရန် Phone (Local)
Category ရွေးချယ်မှု Spending Breakdown ပြသရန် Phone (Local)
Notification အချိန် Daily Reminder ပို့ရန် Phone (Local)
Alert ပမာဏ Big Spender Alert စစ်ဆေးရန် Phone (Local)
ငွေကြေးအမျိုးအစား Currency Label ပြသရန် Phone (Local)
② မကောက်ယူသော အချက်အလက်များ

Nomi App သည် အောက်ပါ အချက်အလက်များကို လုံးဝ မကောက်ယူပါ—

  • ❌ Email၊ ဖုန်းနံပါတ် (Account မလိုဘဲ သုံးနိုင်သည်)
  • ❌တည်နေရာ (Location Data)
  • ❌ဖုန်း Contact များ
  • ❌ကင်မရာ / ဓာတ်ပုံများ
  • ❌Bank Account သို့မဟုတ် Credit Card အချက်အလက်
  • ❌Analytics သို့မဟုတ် Tracking Data
  • ❌Device ID သို့မဟုတ် Advertising ID
③ Data သိမ်းဆည်းပုံ
  • ✅Data အားလုံးကို သင့် Phone ၏ Local Storage (SQLite) တွင်သာ သိမ်းဆည်းသည်
  • ✅ကျွန်ုပ်တို့၏ Server သို့ မည်သည့် Data မျှ မပို့ပါ
  • ✅Internet ချိတ်ဆက်မှု လုံးဝ မလိုဘဲ App အလုပ်လုပ်သည်
  • ✅Third-party Analytics ဝန်ဆောင်မှု မသုံးပါ
  • ✅Data ကို မည်သည့် ကုမ္ပဏီသို့မဆို မရောင်းချပါ မမျှဝေပါ
④ Notification ဝန်ဆောင်မှု

Nomi App သည် Notification ၂ မျိုး ပို့သည်—

  • 🔔Daily Reminder — သင် ရွေးချယ်သောအချိန်တွင် မှတ်တမ်းတင်ရန် သတိပေးချက် (Phone Local Notification)
  • ⚠️Big Spender Alert — သင် သတ်မှတ်ထားသော ပမာဏ ကျော်လွန်ပါက ချက်ချင်း သတိပေးချက် (Phone Local Notification)

Notification များသည် Phone ၏ Local Notification System မှသာ ပို့သည်။ External Server မှ မပို့ပါ။ Settings မှ ပိတ်ထားနိုင်သည်။

⑤ Data ပျောက်စီးနိုင်သော အခြေအနေများ

Local Storage သုံးသောကြောင့် အောက်ပါ အခြေအနေများတွင် Data ပျောက်ဆုံးနိုင်သည်—

  • ⚠️App ကို Uninstall လုပ်ပါက
  • ⚠️Phone ကို Factory Reset လုပ်ပါက
  • ⚠️Phone ပျောက်ဆုံး သို့မဟုတ် ပျက်စီးပါက

💡 Data ကာကွယ်ရန် Settings မှ CSV Export ကို အသုံးပြုပြီး Backup လုပ်ထားပါ။

⑥ ကြော်ငြာများ (Advertisements)

Nomi App တွင် Google AdMob ကြော်ငြာများ ပါဝင်နိုင်သည်။ AdMob သည် ကြော်ငြာပြသရန် Device Information အချို့ကို အသုံးပြုနိုင်သည်။

AdMob ၏ Privacy Policy ကို policies.google.com/privacy တွင် ကြည့်ရှုနိုင်သည်။

⑦ ကလေးများ၏ ကိုယ်ရေးလုံခြုံမှု

Nomi App သည် အသက် ၁၃ နှစ်အောက် ကလေးများအတွက် မဟုတ်ပါ။ ကလေးများ၏ Data ကို သိမ်းဆည်းခြင်း၊ ကောက်ယူခြင်း လုံးဝ မပြုလုပ်ပါ။

⑧ မူဝါဒ ပြောင်းလဲမှုများ

Privacy Policy ကို အချိန်အခါ ပြောင်းလဲနိုင်သည်။ ပြောင်းလဲမှုများကို ဤစာမျက်နှာတွင် ဖော်ပြမည်ဖြစ်ပြီး "နောက်ဆုံးပြင်ဆင်သောရက်" ကို Update လုပ်မည်။
